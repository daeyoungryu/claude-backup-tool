개인정보처리방침 / Privacy Policy

최종 수정: 2026-09-12 · Last updated: 2026-09-12

Claude Workspace Backup 은 단일 사용자(소유자 본인)를 위한 개인 백업 도구입니다. 이 방침은 이 도구가 Google API 를 사용하는 방식을 설명합니다.

Claude Workspace Backup is a personal backup utility for a single user (its owner). This policy describes how it uses Google APIs.

1. 수집하는 개인정보 / Information collected

없습니다. 이 도구는 개인정보를 수집·저장·전송하지 않습니다. 분석 도구, 추적, 광고, 쿠키를 사용하지 않습니다. 서버를 운영하지 않습니다.

None. This tool does not collect, store, or transmit personal information. It uses no analytics, tracking, advertising, or cookies. It operates no server.

2. 데이터가 저장되는 곳 / Where data is stored

이 도구는 사용자 본인의 컴퓨터에 있는 파일을 사용자 본인의 Google Drive 계정으로 복사합니다. 데이터는 그 두 곳에만 존재합니다. 다른 목적지는 없습니다.

The tool copies files from the user's own computer to the user's own Google Drive account. Data exists only in those two places. There is no other destination.

3. Google 사용자 데이터 접근 / Google user data access

  • 요청하는 권한은 https://www.googleapis.com/auth/drive.file 하나뿐입니다.
  • 이 범위는 이 도구가 직접 만든 파일에만 접근을 허용합니다. 사용자 Drive 의 기존 파일, 사진, 문서는 이 도구에 보이지 않습니다.
  • 접근 토큰은 사용자 컴퓨터의 로컬 rclone 설정 파일에만 저장되며 외부로 전송되지 않습니다.
  • Google 사용자 데이터를 사람이 열람하지 않으며, 제3자에게 제공·판매·양도하지 않습니다.
  • Google 사용자 데이터를 광고 목적이나 인공지능 모델 학습에 사용하지 않습니다.
  • The only scope requested is https://www.googleapis.com/auth/drive.file.
  • That scope grants access only to files this tool itself created. Existing files, photos, and documents in the user's Drive are not visible to it.
  • Access tokens are stored only in the local rclone configuration file on the user's computer and are never transmitted elsewhere.
  • Google user data is not read by any human, and is not shared, sold, or transferred to third parties.
  • Google user data is not used for advertising or to train artificial-intelligence models.

4. 제3자 제공 / Third parties

없습니다. 데이터는 사용자 본인의 컴퓨터와 사용자 본인의 Google Drive 사이에서만 이동합니다.

None. Data moves only between the user's own computer and the user's own Google Drive.

5. 보관과 삭제 / Retention and deletion

백업 파일은 사용자가 직접 지울 때까지 사용자의 Google Drive 에 남습니다. 사용자는 언제든 Google Drive 에서 파일을 삭제하거나, Google 계정 권한 페이지에서 이 애플리케이션의 접근 권한을 취소할 수 있습니다.

Backup files remain in the user's Google Drive until the user deletes them. The user may delete the files at any time, or revoke this application's access at Google Account permissions.

6. 방침 변경 / Changes

이 방침이 바뀌면 이 페이지의 "최종 수정" 날짜를 갱신합니다. Changes to this policy will be reflected in the "Last updated" date above.

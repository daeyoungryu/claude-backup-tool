Claude Workspace Backup

개인용 백업 도구 — a personal backup utility

이 페이지는 개인 개발 워크스페이스를 백업하는 도구를 위한 것입니다. rclone 을 사용해 소유자 본인의 파일을 본인의 Google Drive 계정으로 복사합니다.

This page belongs to a personal backup utility. It uses rclone to copy the owner's own files to the owner's own Google Drive account.

무엇을 하는가 / What it does

  • 로컬 파일(소스 코드 아카이브, 설정, 공개 데이터셋)을 소유자의 Google Drive 로 복사합니다.
  • Google Drive API 를 drive.file 범위로만 사용합니다 — 이 도구가 직접 만든 파일에만 접근합니다.
  • 단일 사용자용입니다. 가입, 계정, 다중 사용자 기능이 없습니다.
  • Copies local files (source archives, configuration, public datasets) to the owner's Google Drive.
  • Uses the Google Drive API with the drive.file scope only — it can access only files it created.
  • Single-user. There is no sign-up, no account system, and no multi-user functionality.
